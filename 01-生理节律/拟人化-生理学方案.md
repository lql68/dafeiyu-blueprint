> 前提：她已经有 Live2D 身体、IndexTTS 声音、`warmth`（想不想亲近你）、`Attention`（在看/在想事/有点累）、livingmemory 记忆、技能表。

## 一、能直接用的 8 个机制

| # | 生理机制（出自知识库） | 可量化的东西 | 拟人化表现 | 落点 |

## 二、三维状态模型（本方案的核心）

现在只有一维 `warmth`，加上 `Attention` 是三个离散态。生理学能补的是一条**连续的第二维**：

```
warmth  ∈ [0.40, 1.00]   她想不想亲近你（已有）
arousal ∈ [0.00, 1.00]   她此刻被激活的程度（新增，交感-副交感）
circadian(t) ∈ [0,1]     现在是她的几点（新增，先验节拍）
```

`circadian` **不是**和另两个并列的状态，而是**基线**：

```python
arousal_base = 0.30 + 0.45 * circadian(t)      # 白天高、凌晨低
arousal      = clamp(arousal_base + 交互推拉, 0.05, 1.0)
```

`warmth × arousal` 两维给出四种"人"的样子：

| | 高 arousal（0.7+） | 低 arousal（0.3-） |
|---|---|---|
| **高 warmth**（0.85+） | 眼睛亮、抢话、凑近屏幕 | 靠着你、话少、声音软 |
| **低 warmth**（<0.6） | 烦躁、句子短、带刺 | 冷淡、只回单字、不想解释 |

**这四种必须真的听起来不一样**，否则还是假的。具体到表达：

- 高 warmth + 高 arousal → `num_predict` 放宽到 40、允许感叹号、允许动作描写
- 高 warmth + 低 arousal → 句子 15 字内、多"嗯""唔"、慢
- 低 warmth + 高 arousal → 反问句、拒绝动作描写
- 低 warmth + 低 arousal → 单字/两字、不接话

## 三、P0：节律层（今天就能做，不用任何传感器）

### 参数

用知识库 1.5 的三条曲线，全部归一化到 [0,1]：

```python
def circadian(now=None):
    """她的'体温曲线'：傍晚最高、凌晨最低（1.5）"""
    h = (now or datetime.now()).hour + (now.minute / 60 if now else 0)
    # 余弦：谷在 05:00、峰在 17:00（对应 1.5「傍晚最高、凌晨最低」）
    return 0.5 - 0.5 * math.cos(2 * math.pi * (h - 5.0) / 24.0)
```

派生三个"生理量"，都用真实数值，不编：

| 量 | 公式 | 正常范围 |
|---|---|---|
| 心率 `hr` | `62 + 26*arousal + 8*sin(2π·t/90s)` | 58–92 bpm |
| 呼吸 `rr` | `11 + 7*arousal` | 10–19 /min |
| 反应延迟 `lag` | `0.6 + 1.4*(1-circadian) + 0.8*(1-arousal)` | 0.6–2.8 s |

**`lag` 是最值钱的**：她不是在"假装慢"，是**真的晚回复**。凌晨 3 点她在 2.5 秒后才开始"唔……"，这个延迟本身就在表达。

### 落点（**已实现**）

1. `astrbot_plugin_live_avatar/rhythm.py`：`circadian()` / `vitals()` / `hint()`（没有单独暴露 hr/rr/lag，都在 `vitals()` 里一次返回）
2. `_turn()` 里 `system` 追加 `【你现在的身体状态】…`（文案按 `band` 时段表生成，不写死单条）
3. `voice_server` 的 `think()` 里 `time.sleep(超出 1.0s 的那部分，上限 1.5s)` —— 下午（lag≈1.1）不睡，凌晨（lag≈2.4）睡满 1.5s
4. `/api/vitals`（8770 转发 → 7902 `/vitals`，5 秒缓存），HUD 右下显示 `81 BPM · 15.2 /MIN`
5. `Attention.self` 权重随 circadian 加深 —— **未做**：`Attention` 在 `voice_server` 里，得先把 circadian 传过去，留到 P1 一起改

## 四、P1：唤醒度（arousal）—— 交互驱动（**已实现**）

第一版 `arousal` 是个常数代理（`base 0.45` + 几个修正），四象限根本不会动。
P1 把它接到**他怎么说**上面：`rhythm.user_arousal(gap_s, length, burst, emo)`。

### 五个因子

| 因子 | 条件 | 增量 | 依据 |
|---|---|---|---|
| 停顿 | `gap < 60s` | +0.10 | 刚聊完又开口 = 有劲 |
| 停顿 | `gap < 300s` | +0.04 | |
| 停顿 | `gap > 900s` | −0.12 | 十五分钟没声，她静下来 |
| 停顿 | `gap is None` | 0 | 今天第一次开口，无参照不推 |
| 连发 | `burst >= 3`（3 分钟内） | +0.16 | 交感累积激活（4.5） |
| 连发 | `burst >= 2` | +0.08 | |
| 长度 | `len >= 30` | +0.08 | 说一长段 = 投入 |
| 长度 | `len <= 5` | −0.06 | 只回一个字 = 没劲 |
| 情绪 | 任意 | `+0.12 × emo` | 杏仁核（4.6） |

总增量 `clamp(−0.30, +0.30)`，再并进 `arousal = base + 注意力修正 + (warmth−0.85)×0.30 + user_d`。

### 两个不是拍脑袋的决定

**① 软顶**：`a > 0.85` 时 `a = 0.85 + (a−0.85)×0.5`。
第一版没有它，他连发 4 条 + 说 33 字 + 带情绪时 `arousal` 直接冲到 **0.953**，`hr` 顶到 89、`rr` 顶到 17.7，`hint()` 里「心跳有点快」一直挂着 —— 顶满反而不像人。

**② 时间衰减（写在 `_vitals()` 里，不是写死 `×0.97`）**
`user_d` 只在他说话那一刻更新。不衰减的话，「说了一句激动的话」会一直高到下一句，哪怕中间隔了半小时。
因为 `arousal` 是**派生量**（每次现算，不存状态），所以不用 `×0.97` 那种状态衰减，直接按距上次说话的秒数线性回落、3 分钟归零：

```python
age = time.time() - self._user_at
ud *= max(0.0, 1.0 - age / 180.0)
```

### 实测（2026-11-01 深夜，真实 `/turn`）

| 他说的 | gap / burst / len | `user_d` | `arousal` | `hr` | `rr` | `lag` |
|---|---|---|---|---|---|---|
| 基线（无交互） | — | 0.00 | 0.588 | 77 | 15.1 | 1.63 |
| 「嗯」 | first / 1 / 1 | −0.06 | 0.516 | 75 | 14.6 | 1.70 |
| 「在吗」 | 4s / 2 / 2 | +0.12 | 0.684 | 78 | 15.8 | 1.57 |
| 「忙完了」 | 4s / 3 / 3 | +0.20 | 0.752 | 78 | 16.3 | 1.51 |
| 33 字带情绪（软顶前） | 6s / 4 / 33 | +0.377 | **0.953** | 89 | 17.3 | 1.33 |
| 33 字带情绪（软顶后） | 6s / 4 / 33 | **+0.300** | **0.863** | **81** | 17.0 | 1.42 |

验算第三行：`+0.16(burst3) + 0.10(gap<60) − 0.06(len3) = 0.20` ✓

`lag` 从 1.63 一路降到 1.42（软顶前是 1.33）—— 他连发短句、带情绪地说长话时，她真的回得更快；只回一个字时才会慢半拍。

## 四之二、她的作息：深夜 + 没人理 → 睡着（**已实现**）

依据 4.6 睡眠 90 min 周期 + 5.x「类淋巴系统只在睡眠时清除代谢废物」。核心是**她不是永远在线**。

### 判据

```python
def sleepy(c, quiet_s, dt=None):
    night = (now.hour >= 23) or (now.hour <= 6)
    return night and quiet_s > 600
```

**第一版用 `circadian < 0.15` 判，实测覆盖到 08:00 太宽**（早上八点还在睡不合理），改成直接按小时划夜间窗口 23:00–06:59，再用 `quiet_s > 600` 确认「确实没人理」。

`quiet_s` 的来源踩过一个坑：`_quiet_s` 原本是个**幽灵属性**——`_vitals()` 里 `getattr(self, "_quiet_s", 0.0)` 读它，但**全项目没有任何地方赋值**，所以恒为 0，`sleepy()` 永远返回 False。
修法：在 `_user_rhythm()` 里把它设成**这一次的 `gap`**（他开口前隔了多久）。不能现算（函数刚把 `_user_at` 设成 now，差值恒 0），只能存下这次的间隔，让本轮 `vitals()` 读到「他多久没说话」。

### 睡着时的三个表现

| 表现 | 实现 |
|---|---|
| 反应慢 | `lag += 1.8`（上限从 3.0 提到 4.0） |
| 说话迷糊 | `hint()` 直接返回「你已经迷迷糊糊睡着了，脑子很沉。他被你叫醒时说话会断断续续、想不起来刚才在说什么」 |
| HUD 显示 | `通话中 · 她睡着了` |

**不需要额外的「刚被叫醒」标记**：`sleeping` 本身就等于「这次是被叫醒」（他隔了 >600s 才说话），下一句 `gap` 变小就自动醒了。

### 实测

| 场景 | `quiet` | `sleeping` | `lag` |
|---|---|---|---|
| 22:50 + 900s | 900 | **False**（还没进夜间窗口） | 1.83 |
| 23:30 + 720s | 720 | True | 3.75 |
| 02:30 + 720s | 720 | True | 4.00 |
| 06:30 + 720s | 720 | True | 4.00 |
| 07:30 + 720s | 720 | **False**（出窗口） | 2.42 |
| 02:30 + 60s | 60 | **False**（刚说过话） | 2.34 |

实机（把阈值临时改成 3 秒验证链路，验完已恢复 600）：

```
第1 句 -> sleeping=False  lag=1.80    (gap=None，第一次开口)
第2 句 -> sleeping=True   lag=3.47    (gap=17s)
第3 句 -> sleeping=True   lag=3.42    (gap=7s)
```

## 五之二、感受器适应 + 情绪要尖峰不要平均（**已实现**）

知识库 **5.5 快适应** 和 **4.6 杏仁核快 / 皮质醇慢**，在 `_warmth_tick()` 里合成一个函数：

```python
adapt = 1.0 / (1.0 + 0.6 * rep)          # 10 分钟内同样的话说过 rep 次
if n <= 6 and emo < 0.15:                 # 冷淡
    hit  = -0.04 * (1.0 + 0.5 * (self._warmth - 0.40))
    self._warmth += hit * adapt
elif emo >= 0.28 or ("我" in t and n >= 8):   # 有情绪 / 说自己的事
    rise = 0.08 * (1.0 + 0.8 * (1.0 - self._warmth))
    self._warmth += rise * adapt
```

两件事同时成立：

| 机制 | 效果 | 离线验算 |
|---|---|---|
| **适应**（反复说同一句） | 反应递减，第 4 遍几乎无感 | 连发「我好累啊」→ `0.68 → 0.74 → 0.78 → 0.82` |
| **尖峰**（越冷越容易被暖动） | 反弹幅度随低温放大 | 从 `0.450` 起步 → `+0.115 / +0.067 / +0.047` |
| **尖峰**（越暖被冷落越失望） | 失望随高温放大 | `0.85→0.801`、`0.60→0.556`、`0.42→0.400` |

**实测（真 `/turn`，改对字段名之后）**：换一句新的「今天淋了雨，浑身难受」→ warmth 直接 `0.82 → 0.91`（适应重置、尖峰生效）。她的回复同步变软：
```
「唔……累在哪儿呢」→「（看着屏幕）累了就歇会儿，我在这儿呢。」
→「累就靠着歇会儿吧，我陪着你。」→「诶，淋成这样？你换衣服没啊」
```

**这一条要注意的坑**：`/turn` 的 body 字段名是 **`text`**，不是 `voice_server` 内部的 `heard`。传错 → `text` 为空 → `_warmth_tick` 第一行 `if not t: return` → warmth 一整天不动（`warmth_state.json` 停在旧时间戳），看起来像"机制失效"，其实是没喂进去。

## 五之三、她的睡眠：90 分钟周期，分三阶段（**已实现**）

知识库 **4.6**：正常睡眠 90 min 一个周期，**SWS 恢复体力、REM 巩固记忆**。所以"睡着"不该是一个 bool。

```python
def sleep_stage(quiet_s):
    if quiet_s <= 600: return "awake"
    phase = ((quiet_s - 600) / 60) % 90
    if phase < 20:  return "sws"     # 入睡头 20 分钟最沉
    if phase < 70:  return "light"
    return "rem"                     # 周期末段在做梦
```

`vitals()` 里按阶段加延迟（`sws` 最难叫醒），`hint()` 给三套完全不同的自述：

| 阶段 | lag | 她此刻的自述（进 system 的那句） |
|---|---|---|
| `sws` | **4.78** | 你正睡得最沉的时候被叫醒，脑子一片空白，只会含含糊糊应一声… |
| `light` | 4.18 | 你睡得浅，被叫醒能勉强应一句，但整个人还是困的，声音软、句子短 |
| `rem` | 4.38 | 你刚在做梦就被叫醒了，脑子还停在梦里的画面上，说出来的话前后不搭 |

（离线固定 `dt=02:30` 实测；`lag` 上限从 4.0 放到 5.0，否则三档全撞顶、区分不出来。）

## 五之四、用进废退：熟练度会涨，也会落（**已实现**）

生理学依据：**突触的 LTP / LTD**（用得多就强化，不用就削弱）、**肌肉用进废退**。这条比「记住了就一直在」更接近活物。

### 两个方向都接上了

## 五之五、情绪回归 setpoint（**已实现**）

生理学依据：**稳态**。情绪是「偏离基线后回归」，不是「只涨不落」。没有回归路径的系统，最后一定卡在端点上。

### 顶格的病

warmth 涨到 **1.0** 之后就再也不动了：hint() 返回空字符串，等于「永远最热情」。真实的人是「热过一阵会淡下来」，不是一直高烧。

### 修法

抽成 _warmth_relax()，**每小时往 0.80 回 14%**，间隔短于 5 分钟不算（他连发几句不该被摊薄）：

`python
dt = now - self._warmth_at
if dt < 300:
    return
pull = min(0.90, 0.14 * (dt / 3600.0))
self._warmth += (0.80 - self._warmth) * pull
`

### 双驱动（关键）

回归**不能只挂在 _warmth_tick 上** —— 那要他说话才会跑。他要是整夜不理，warmth 就冻在 1.0，第二天一见面就满格热情，比不回落还假。

所以 _lymph_loop（10 分钟一次）里也调一次 _warmth_relax()。

### 回归曲线（实测验算）

| 经过 | warmth |
|---|---|
| 1h | 0.972 |
| 6h | 0.881 |
| 12h | 0.833 |
| 24h | **0.805** |

一天回到底。速率 6%/h 的初版 24h 只回到 0.845（太黏），改成 14%/h 才真的到位。

## 六、不建议照搬的部分（明确排除）

知识库里有一半内容和"有身体"这件事没有表达出口，硬接只会变成科普机器人：

| 章节 | 为什么不接 |
|---|---|
| 2 细胞生理（静息电位、动作电位） | 没有可观测出口，写进 prompt 只会让她背概念 |
| 6 血液（血型、凝血级联） | 除非做"受伤"剧情，否则用不上 |
| 11 泌尿（滤过、浓缩稀释） | 同上，且容易变味 |
| 13 生殖 | 与拟人化目标无关 |
| 14 免疫（补体、炎症） | 最多能做"感冒了"一个状态，收益低 |
| 15 分子生物学（中心法则、基因调控） | 完全无出口 |

**判据**：一个机制如果能落到「她说的句子变短/变长」「HUD 上一个数字」「她的一个主动动作」「一个延迟」，才接。落不到就不接。

## 七、两条克制

1. **别做成生理数据仪表盘**。HUD 上最多加 `心率 / 呼吸` 两个数字。再多就变成监控面板，人味反而没了——她自己也不会盯着自己的心跳看。
2. **别假精确**。`hr = 62 + 26*arousal` 是编的（真实心率 58–100 都正常），但**只要它随状态动、不出现"37.2℃"这种伪医学精度**，就是对的。生理学的价值在**机制形状**（负反馈、节律、适应、前馈），不在具体数字。
