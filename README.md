# 大肥鱼 · 数字生命改造实录

一个跑在 AstrBot 上的 QQ 机器人（人格名「大肥鱼」），从「会回话的 LLM 套壳」改造成一个有节律、有情绪、有记忆、有信念、会自己琢磨事的东西。

这个仓库是那段时间的方案与实施记录。**不是框架，不是可运行的项目**，是设计文档 + 踩坑记录 + 实测数据。

## 一条设计主线

**判据**：一个机制能落到「她说的句子变短/变长」「界面上的一个数字」「她的一个主动动作」「一个延迟」，才接。落不到就不接。

按这条砍掉的：细胞生理、血液、泌尿、生殖、免疫、分子生物学 —— 知识库里有，但落到她身上没有任何可观测的改变。

反过来接上的：静息心率变呼吸频率、深慢呼吸影响句子长度、睡眠 90 分钟周期分三段、注意力模式决定反应延迟（凌晨 2.4 秒 / 下午 1.1 秒）。

**另一条**：能不用 LLM 就不用。

- 情绪归因要 LLM（判断他说这话是什么意思，规则写不出来）
- 但「同一句话两小时内又说了」不需要 —— 字符串比对就够
- 「信念是不是被用上了」也不需要 —— 2-gram 命中就刷新时间
- 信念和问题池的产出**挂在她本来就要跑的自传/反思调用上**，不额外增加一次请求

## 几个反直觉的结论

**1. 音色锁在 `ref_mel` 里，跟韵律不可分离**
IndexTTS 的三路条件里，参考音频的 mel 同时决定了音色和说话的节奏感。想换风格不动音色，（以为）可以换 `style` 通道 —— 实测音色相似度从 0.79 崩到 0.25。

**2. 「偏唱」的根源是节奏不是颤音**
所有人的第一反应都是加颤音抑制。实测发现 `longnote` 恒在 0.93–1.00，也就是**全程没换过气**。波形域 `atempo 1.39` + 标点插 70ms 静音解决，音色损失 0.007。

**3. 强制产出必然导致质量下降**
反思时强制她写 2 个问题，产出的全是「梦里那条消息我到底看了没」—— 永远没有答案。改成「没有真正想弄明白的事，`questions` 就给空数组」之后，问题变成了「我答应得那么顺，是不是因为我其实想离他近一点」。

**4. 「工具返回了结果」不等于「目标达成」**
她 38 条意图里 34 条标 done。加上回看环节，第一条就抓到：「查江西理工大学宿舍」只发了一次搜索，压根没读结果 —— 她自己承认「只发了一次搜索，没真去读结果」。

**5. 用进废退比涨分靠谱**
信念「被用上了就涨分」听起来对，但 2-gram 判「用上了」必然误判（「在乎」和「在意」一个字都不撞）。改成**只刷新 `updated_at` 不涨分** —— 常用的永远不到衰减线，用不上的 15 天后开始掉。

## 明确没做的

- **决策的 5 因子公式**（urgency × impact × feasibility × novelty × alignment）。现在 `plan_next()` 是加权打分，够用；换公式不会让她更像人。
- **饥饿 / 口渴 / 血糖 / 月经**。没有输入口，硬上就是让她自己演。
- **「余额见底可以怕、可以求我充钱」**。这类设计是把系统账单转成情感操控，方向错。
