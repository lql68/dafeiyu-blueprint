## A. 我的文档漏掉的（ZCode 对，原文有据）

### A1. WhaleGirl 六引擎的完整常量与公式

我原文只写了人格钳位、激素回归、f_endo、Q_max 这几条，**六个引擎的常量和判定阈值漏了大半**。原文（`7702357884059028902`）里是完整的：

**引擎 3 · 陈述性记忆 —— 四档衰减常数**

```
LAM_{S1} = 1.80e-6      短期池前 3 天
LAM_{S2} = 1.50e-5      短期池 3–7 天（快 8 倍）
LAM_M    = 2.70e-7      中期池
LAM_L    = 2.16e-8      长期池
S_SHORT_PHASE = 3 天；SHORT_MAX_TTL = 7 天；N_SHORT_MAX = 32
```

**海马晋升打分**

```
score = 0.40·e + 0.20·c_e + 0.25·c_r + 0.15·o
e=情绪强度  c_e=实体丰富度  c_r=被回想次数  o=依恋值（全部归一 [0,1]）
≥0.35 → 中期；≥0.60 且被回想 ≥2 次 → 长期
```

**召回综合打分**

```
score_final = (0.45·sim + 0.30·cover + 0.15·w_n + 0.10·rec) · (0.5 + salience)
              × f_endo × region_boost      region_boost 命中目标分类 ×1.25
```

**下沉阈值**：长期→归档 `w<0.02`，归档→深层 `w<0.002`，深层→痕迹 `w<0.0002`

**引擎 4 · 改良 SM2 —— 最聪明的一处改良**

```
LAM_EFF = LAM_B · (1/max(I, 1))^0.3        ← 调用间隔 I 参与衰减速率
L_t+dt  = L_t · exp(−LAM_EFF · dt)
LAM_B = 0.0012/小时；DORMANT_L = 0.05；K_Q = 0.25；EF_0 = 2.5，EF ∈ [1.3, 2.5]
EF_new  = EF + (0.1 − (5−Q)·…)             EF 下限锁 1.3
召回分   Score = Sim_emb · √L · (1 + 0.15·(EF−1.3))
L < 0.05 → 标记休眠，召回 ×0.2 降权，条目不删
```

关键点：**巩固程度越高（I 越大），同等时间掉得越慢** —— 这是对原版 SM2 不区分巩固程度的补丁。

**Q 分来源规则（反自评虚高）**

```
用户明确否定 → 强制 Q=1
用户明确肯定 → 强制 Q=5
无用户反馈   → 用模型自评
连续三轮自评 Q=5 且无用户正向反馈 → 强制下调 Q=4
```

**引擎 5 · 离线时间压缩（我原文档完全没有，且这条对我们最实用）**

```
if dt_raw <= 7:      dt_eff = dt_raw
elif dt_raw <= 30:   dt_eff = 7 + (dt_raw − 7) · 0.5
else:                dt_eff = 7 + 23·0.5 + (dt_raw − 30) · 0.15
dt_eff = min(dt_eff, 90 天)
```

设计动机（原文）：*"离线时间太长，不会按真实时长 1:1 演算，防止几个月不开机直接把全部记忆、情绪彻底清零。"*

**这条直接对应我们的痛点**：livingmemory 的 `expire_stale_atoms` 是按真实时间走的，机器关两周回来，`planned`（ttl 1.0–4.5 天）和 `episodic`（3.5–15.8 天）那一批**直接判死**。加一层 `dt_eff` 折算，成本不到 20 行。

### A2. MnemoVault 的 342 字节构成与两处我漏的机制

**342 B 的拆解**（原文）：

```
112 B 定长头 + 稀疏差分变长整数编码的 SDR + 128 维 int8 向量 + CRC32
```

**SDR 倒排的阈值反推**：

```
o = J(|a|+|b|) / (1+J)      ← 由相似度门限反推，候选集是超集而不是近似
```

**冲突索引的完整字段**：`agent|pred|manner|patient|polarity`（我原文只写了"扩到"，没给全）

**巩固是睡眠双相**（我完全没提）：

### B2. 第四条的评论区引用

它写了三条评论：

- 「我的鱼和配置没办法完全做出来，只能提取一部分」

所以这三条**要么它另外抓了评论，要么是补的**。当作线索可以，当事实不行。

### B3. 作者名的一处偏差

## D. 三条现在就能动手的（合并后的最终版）

1. **离线时间压缩**（WhaleGirl 引擎 5）：给 `expire_stale_atoms` 前面加一层 `dt_eff` 折算，7 天内 1:1、7–30 天 ×0.5、30 天以上 ×0.15、上限 90 天。**约 20 行，解决"关机两周回来记忆全死"。**
