## 1. MnemoVault：把一句话压成 342 字节

**作者**：用户89182870592（粉丝 9 / 获赞 780）
**发布**：2026-10-31 17:36
**数据**：赞 181 / 评 6 / 藏 165 / 转 47
**仓库**：GitHub 搜 `bcf-mnemovault`，MIT，npm `@rain13sad/dsh-mnemo-*`（10 个包已发布）

### 它解决什么

给 **DeepSeek Harness** 用的长期记忆 + 情感插件族。核心命题：**注入上下文时不回放原文**。

现在的主流做法（包括我们自己的 livingmemory）是：检索 → 把原文塞进 prompt。它反过来：**只渲染一行结构化文本，稳态约 107 token/轮，比整段摘要省约 90%**。

### 记忆细胞（MC03 格式）

一条记忆 = 定长结构：

```
2048 位稀疏码 (SDR) + int8 向量 + 有类型超边 + 压缩残差
```

单条 **844 B → 342 B**，四个具体判断换来的：

| 优化 | 做法 | 理由 |
|---|---|---|
| 时间戳 | i64 → u48 | 毫秒精度够用 8900 年 |
| 稀疏位图 | 定长位图 → 有序下标 + 差分编码 | 2048 bit 里只有 8 个 1，97% 是零 |
| 向量维度 | 256 → 128 | Recall@8 仍是 0.941 |
| 冷层量化 | 4 bit 量化**前先归一化** | 否则哈希向量的 ±4~±8 取整后变零向量 |

结果：**存储比 0.84 倍，粗粒度切分档 0.68 倍** —— 结构化存储比存原文更省。

### 遗忘：七因子打分

每轮过七个因子：激活度、重要度、情绪强度、关联度、叙事角色、用户锚定、间隔效应，**减冗余**。

- 频率与近因用 ACT-R 统一：`B = ln Σ(t − t_j)^−0.5`（天然幂律）
- 再叠一层陈旧包络：**30 天不折损，730 天到地板**
- 分数 → 六档处置 → 五层存储（热 / 温 / 冷 / 归档 / 墓碑），**一次只走一级**

两条写死的规则：

> 1. 闸门只封顶层、**不抬分数**（否则每条用户发言都永远温热）
> 2. 墓碑不是删除 —— 行、摘要、槽位、边全在，只有字节被释放，物理删除要显式审批

还有「再巩固」：每次提取让记忆重新可塑，提取即强化；被纠正时进入可塑窗口；反复提取且从不出错的记忆逐渐硬化。

### 情感：存为参数，不是台词

```
评价 → PAD → 心境 → 关系 → 人格锚
```

全部存为**普通记忆**。OCC 分类用 22 类里判据互斥的纯函数子集，**不调 LLM** —— 理由写得很硬：*"情感逻辑不能被模型随机性污染"*。

情绪事件五态状态机，两条硬规则：
- **未获回应的情绪不衰减**，open 状态下强度只增不减
- 本轮效价低于 −0.3 时**强制回应、禁止发散**

其他几条值得抄的：
- 情感记忆不会被时间抹平（强度够大的只降到温层）
- **联想是长出来的不是连出来的**：同轮被一起召回的记忆之间按 Hebbian 规则长边
- 同一条记忆有**事实 / 感受 / 纽带 / 故事**四个视角
- 主动开口 —— 但一半的代码在判断**什么时候不该说话**

### 改主意不覆盖

每条记忆带**两个时间**：事实成立的时间、系统记录的时间 → 能回答"上周我们当时认为用什么"。

用户改主意时不覆盖旧值，而是建 `CONTRADICTS` + `SUPERSEDES` 两条边形成**版本链**。

### v0.5.2 的性能账（这才是最有说服力的部分）

发现一个更蠢的开销：为了算 128 次乘加，**每次召回都把全库 blob 解一遍** —— 解码比计算贵两个数量级。

| 改造 | 前 | 后 |
|---|---|---|
| Q1 加内存向量矩阵（召回 p50） | 18 ms | **4 ms** |
| 去重/冲突用 SDR 倒排（ingest） | 46 ms | **1.8 ms** |
| 冲突索引扩到 `agent\|pred\|manner\|patient\|polarity`（每 5 轮 getCell 次数） | 2026 次 | **16 次** |
| 保留度落盘加单调性剪枝 + 单事务（1 万条一次 pass） | 2066 ms | **658 ms** |

规模实测：

```
222 条  召回 p50 4 ms
822 条  召回 p50 4 ms      ← 不随规模增长
1 万条  召回 p50 20 ms / p95 25 ms / 索引内存 1.6 MB
同语料开关索引对照：召回快 11 倍，ingest 快 21 倍
```

### 九条源码缺陷（三条是"安静地做错"）

| 缺陷 | 后果 |
|---|---|
| `explain()` 跑的是非只读召回 | **"问为什么"本身会抬高那条记忆的访问时间** —— 观察改变了被观察物 |
| 图式的 `noDecay` 写成 `FLAG.noDecay & 0` | 恒等于 0，图式被当普通记忆衰减 |
| `maxResidualBytes` 按 UTF-16 码元截断 | 声称 8192，实际存了约 24 KB 中文 |

两条是写测试时被测试抓出来的。项目把它们写进 README，理由是"这也是它们值得写出来的原因"。

### 坐标系

| 项目 | 是什么 |
|---|---|
| Mem0 | 文本单元 + 向量 |
| Zep / Graphiti | 时序知识图谱 |
| Letta (MemGPT) | 分层上下文 + 自我编辑 |
| cognee | 图 + 向量流水线 |
| **MnemoVault** | 借 Zep 的双时态，但节点是**稀疏码晶胞**不是图节点；借 MemGPT 的分层，但**把"要不要记"从模型手里拿走** |

> 一句话：**别人把"记什么"交给模型，这里把"记成什么形状"交给算法。**
> 代价是抽取质量受规则限制，收益是可复现、可回归、token 可预算。

### 罕见的诚实

- 0.60 倍存储比算术上到不了
- 短于 1.4 KB 的轮次结构化存储**反而更贵**
- 10 万条语料造不出来，所以 1 万条是**合成的**，脚本输出里明写"这个数字不能与真实库比较"
- v0.5.0 的单点采样测了第 400 天和第 900 天，**恰好绕过 365 和 730 两个周年窗口**，三个缺陷一条没抓到；之后改成扫描式，断言单调、可达、不变量

## 2 + 3 + 4. WhaleGirl V5.0：一套完整的心智架构

**发布**：2026-10-30 15:15（#4）/ 更早（#2、#3）
**标签**：#流浪地球2 #数字生命 #deepseek #大肥鱼
**形态**：公式表 + 架构文档（截图长图），不是代码

### 四条设计公理

1. 全部记忆、人格、激素、技能、时间戳**唯一真值存在"数字生命卡"里**；电脑和大模型**不持久留存任何副本**
2. **联想只读**；遗忘、权重更新只由后台定时任务写入。单纯回想不直接加固记忆，回想记为事件，后台统一结算
3. **不读本机系统时间**；时间全由卡内时间戳算。关机离线的时间差，下次插卡批量演算
4. 记忆**只记录发生过的交互**，不脑补推断他人想法；上下文只做挑选截断，禁止模型编造记忆内容

### 五层架构

| 层 | 名称 | 职责 |
|---|---|---|
| 1 | **人格内核锁** | `CORE` 只读签名区（人格向量、身份锚、核心信念，运行期不可改）+ `LIVE` 可变区 |
| 2 | **内分泌心境调控** | 4 类激素，0~1，只改召回权重/技能上限/输出语气，**不篡改记忆内容** |
| 3 | **六大仿生调度分区** | 感知输入 / 联想检索 / 内分泌心境 / 人格内核 / 行为输出规划 / 后台稳态演算 |
| 4 | **双层记忆系统** | 陈述性情景记忆 + 程序性技能记忆（改良 SM2） |
| 5 | **MCP 通道层** | 大模型只是"嘴巴"，不拥有心智数据 |

优先级写死：**人格内核 > 内分泌情绪 > 记忆内容 > 当前对话**

### 关键公式（第 1、2 层）

**人格钳位** —— 单轮对话每个人格维度最多 ±0.12：

```latex
P_{new} = P + clamp(dP, -0.12, +0.12)
```

**人格内核保底** —— 无论多少次负面交互，综合强度不能跌到 0.15 以下：

```latex
‖P_core‖ ≥ 0.15
```

**激素稳态回归** —— 后台 tick，向基线指数回归，半衰期约 34.7 小时：

```latex
h_{t+dt} = h_base + (h_t - h_base) · exp(−λ_H · dt)     λ_H = 0.02 / 小时
基线：h_sero=0.60, h_dopa=0.40, h_cort=0.20, h_oxy=0.50
```

**事件扰动**（以负面冲突为例）：

```latex
h_cort += 0.15 · (1 − h_cort) · s
h_sero −= 0.12 · h_sero · s
h_dopa −= 0.08 · h_dopa · s
h_oxy  −= 0.10 · h_oxy  · s · (1 − R_INERTIA)
```

其中 **依恋惯性** `R_INERTIA = clamp(h_oxy × 0.70, 0.30, 0.85)` —— 依恋越深，负面事件对亲密感的打击被削弱，**避免一次吵架清零长期羁绊**。

**内分泌对记忆召回的加权**：

```latex
f_endo = (1 + 0.30·(h_oxy − 0.5)) · (1 − 0.35 · max(0, h_cort − 0.20)/0.80)
取值范围约 [0.72, 1.15]
```

催产素高 → 羁绊回忆更容易被唤起；皮质醇高于基线（压力）→ **抑制温情记忆的召回**。

**程序性技能 Q 分上限压制**：

```latex
Q_max = 5 · (1 − 0.60 · max(0, h_cort − 0.20)/0.80)
```

### 双层记忆

| | 陈述性情景记忆 | 程序性技能记忆（改良 SM2） |
|---|---|---|
| 遗忘的是什么 | 内容细节：时间、场景、细节逐步淡化 | 熟练度参数，**技能描述文本永久不变** |
| 结构 | `mem` 主表 + `detail` 细节子表（不同细节有**不同遗忘速度**） | 熟练度 `L` / 易度因子 `EF` / 调用间隔 `I` |
| 三级池 | 短期 → 中期 → 长期 | — |
| 关键机制 | 短期池满触发驱逐；**海马打分**（情绪、实体丰富度、回想次数、依恋）决定是否晋升；权重下降发生**主干侵蚀**：先丢动作、对象细节，最后只剩情绪印象 | 成功调用加固熟练度；过低标记**休眠**，降召回优先级，**不删条目** |

长期池继续下沉：`ARCHIVE 潜意识归档 → DEEP 深层摘要痕迹 → TRACE 统计痕迹`。

> **除核心区，所有空间都会遗忘** —— 存储总量在数学上动态平衡，不会无限膨胀。

### 上下文配额（第 5 层）

六维权重：`A 身份内核 / B 自我认知 / C 近期对话 / D 长期陈述记忆 / E 印象羁绊记忆 / F 程序性技能记忆`

- 按场景（普通 / 情绪陪伴 / 技能执行 / 冲突争执）生成基础权重
- 再受**内分泌激素、提问意图、会话轮次、离线时长**二次微调
- 归一后换算各模块 Token 配额，**人格内核设最低配额，永不被裁剪**
- 重要约束：**接口调用失败时，禁止让模型扮演角色**，直接提示心智服务异常

### 数字生命卡（.lifecard）

```
身份校验文件 + 签名人格内核 + SQLite 心智数据库 + 自动快照 + 便携运行环境
```

- **拔卡**：结算全部事件 → 落盘 → 写封存时间戳 → 生成快照
- **插卡**：校验身份锚 → 计算离线 Δt → 批量执行全部后台衰减演算 → 起服务 → 注册 MCP 工具
- **崩溃兜底**：异常断电写崩溃标记，下次启动提示，可恢复快照，**依然计算离线时间**

## 6. 对我们自己这套的映射

我们现在跑的是：**livingmemory（记忆）+ 大肥鱼人格 + 通话页 + 记忆星图**。对照这三条线，有几个能直接用：

### 可以马上做（改动小、收益直接）

| 借鉴点 | 出处 | 我们的现状 | 怎么做 |
|---|---|---|---|
| **闸门只封顶层、不抬分数** | MnemoVault | 我们 `avg_importance` 只有 0.343，63% 低于 0.3 清理线 | 我们的衰减是乘性的，但 `protected_importance_threshold=1.0` 等于没有 —— 改成 0.75 就有保护效果 |
| **未获回应的情绪不衰减** | MnemoVault | 无 | 通话里她说了但用户没接话 → 那条记忆加权；实现成本低 |
| **双时间戳** | MnemoVault / WhaleGirl | 只有 `created_at` | 加 `valid_from`（事实成立时间），能回答"上周我们当时认为用什么" |
| **版本链而非覆盖** | MnemoVault | 改主意就新增一条，检索时两条都出 | 加 `CONTRADICTS`/`SUPERSEDES` 边，检索时优先新值 |
| **人格钳位** | WhaleGirl | 人格是 persona.txt 一段 Prompt，聊几句就可能漂 | 我们没向量化人格，但至少可以**每 N 轮检查一次回复是否偏离 persona 关键词** |
| **回想不加固、后台统一结算** | WhaleGirl | `reinforcement_count` 全是 0 | 我们现在是"读就强化"（`last_accessed_at` 更新），改成"读记事件，后台按批结算" |

### 中期值得做

- **七因子打分**：我们现在只有一个 `importance`（LLM 给的）。至少补上「用户锚定」（是不是用户本人的事）和「间隔效应」（回想间隔），这两个最好算
- **主干侵蚀**：记忆权重掉到一定程度时，只保留情绪印象、丢掉动作/对象细节。这比整条删掉更像人
- **海马打分晋升**：短期池满 → 打分 → 决定晋级。我们现在是直接写库，没有池的概念
- **六维动态配额**：通话场景（情绪陪伴）和 QQ 场景（信息交换）应该用不同配额比例

### 现在不必做

- **器官自举**（digital-life-core）：那是另一个量级的事，且依赖它自己的运行时
- **.lifecard 热插拔**：我们的记忆库已经是单文件 SQLite，天然可搬，不需要专门打包
- **梦境机制**：执念池 + 深夜自主苏醒，需要常驻调度器，且和"她只在被叫时醒"的设定冲突

### 一句话判断

> **MnemoVault 是三条里唯一"今天就能抄到东西"的** —— 它把每一个主张都落到了可复现的数字上（18ms→4ms、46ms→1.8ms、2066ms→658ms），而且明说了自己哪里做不到。WhaleGirl 是一套漂亮的架构设计但没代码，digital-life-core 是另一个野心。
>
> 我们的 livingmemory 现在最缺的不是"记得更多"，是**"忘得更聪明"** —— 767 条原子全 active、72 条早该过期还卡着、`reinforcement_count` 全 0。MnemoVault 那套五层存储 + 七因子打分，正好是对症的药。

## 对 ai-live 真正可抄的三样（修正 ZCode 的判断）

ZCode 那份把重点放在"唯识八识的层次对齐"和"末那识层"。**我的判断不同**：

**① 「心光」比「末那识」更该抄。**
末那识（自我叙事层）是一个**概念**，落地成一张表也行、一段 prompt 也行，收益不好衡量。而"心光"是一个**具体的控制环**：此刻注意力投向外部世界／内部记忆／自身状态。我们现在的 `/turn` 是纯被动——用户说话就回，不说话就空转。加一个"她自己决定此刻看什么"的循环，才会出现"她在发呆"这种状态，而不是"她在等指令"。

**② 「学校」比「巩固（consolidation）」更该抄。**
我们的 `memory_consolidation` 开了但 `trigger=daily`，本质是"睡前把今天的记忆合并一下"——这是**整理**。而"学校"是**排课**：有教学目标、有课程、学完才能玩。落到工程上，它产出的是**可复用的应对范式**（procedure），而不是更短的记忆摘要。

**③ 「保护机制」比「保护机制」这个名字更该抄。**
原文列了五种：警惕回避、拒绝、沉默离开、**降低关系投入**、放弃目标。注意这里全是**行为输出**，不是崩溃。一个会"降低投入"的 AI 伴侣，比一个永远热情的更接近真实依恋——而且它天然防 sycophancy。

**不抄的**：
- **八识命名体系**。恶趣味兔子那条批评是对的：这套词每轮都要花 token 解释，而且五轮内会跑偏。概念价值在"分层对了"，工程价值为零。我们可以按层做，但用大白话命名。
- **"识海四层"的具体实现**。作者没开源，第 6 集才拆解，现在无法验证它到底是四张表还是一段 prompt。
